# AlwaysIME

AlwaysIMEは、Windowsのタスクトレイに常駐して、IMEの状態を制御するアプリです。アプリごとにIMEをオフにする、一定時間入力がなければ元の状態に戻す、MS-IMEのスペースと句読点を切り替える、などができます。

## 動作環境

- Windows 10 と Windows 11
- 管理者権限は不要です（管理者権限で動くウィンドウを操作する場合を除きます。後述）。
- WinUI / UWPなどのモダンUIフレームワークのアプリには対応していません。
- 「MS-IME入力設定」は、Windows 11の新しいMicrosoft IME（互換モードをオフ）専用です。ATOKとGoogle日本語入力では動作せず、対応の予定もありません。

## はじめかた

1. zipを、書き込める場所に展開します（例: ドキュメント、デスクトップ、`C:\Tools`）。**`C:\Program Files`**** には展開しないでください。** 標準ユーザーは書き込めないため、設定とログが保存されません。
2. 実行ファイル（AlwaysIME.exe）を起動します。トレイにアイコンが表示されます。
3. トレイアイコンを右クリックして、メニューから設定を開きます。

同梱のファイルは次のとおりです。

| ファイル | 説明 |
| --- | --- |
| AlwaysIME.dll.config.default | 設定のひな形です。**削除や編集をしないでください。** 無い、または壊れていると、起動しません。 |
| LICENSE.txt | ライセンス（MIT）です。 |
| AlwaysIME.portable | 任意です。あると、初回起動時にポータブルとして動作します。 |

## トレイメニュー

トレイアイコンを右クリックすると、次の操作ができます。

- **少し無効 / しばらく無効 / 再度有効**: 一時的にAlwaysIMEの機能を止めます。止める時間は、設定の「SuspendFewTime」「SuspendTime」で決まります。
- **句読点・スペースの切替**: 「MS-IME入力設定」が有効なときに、設定した値へ切り替えます。もう一度押すと、初期値に戻ります。
- **設定を表示**: 設定画面を開きます。
- **IMEオフに登録**: 前面のアプリ名またはウィンドウタイトルを、IME-OFFの一覧に追加します。制御モードが2のときは、表示が「IMEオンに登録」に変わり、追加したものはIMEがオンになります。
- **常駐の終了**: AlwaysIMEを終了します。終了時に、スペースと句読点は初期値に、キー割り当ては変更前の設定に戻ります。

アイコンにマウスを重ねたとき、「AlwaysIME（管理者）」と出れば、管理者権限で動いています。

## 設定

設定画面は、左のカテゴリーから選びます。「保存して閉じる」または「適用」で反映されます。

| カテゴリー | 内容 |
| --- | --- |
| 制御しないアプリ | IMEを一切操作しないアプリ |
| IME-OFFアプリ（制御モード2では IME-ONアプリ） | アプリを切り替えたとき、IMEをオフにするアプリ。制御モードが2のときは通常がオフなので、載せたアプリだけオンになります |
| IME-OFFタイトルパターン（制御モード2では IME-ONタイトルパターン） | ウィンドウタイトルが一致したらIMEをオフにする、正規表現。制御モードが2のときは、一致したらオンになります |
| タイトル除外タグ | タイトルの変化を判定するとき、無視する部分の正規表現 |
| 未入力タイムアウト | 入力がない時間（秒）。経過すると、IMEを初期状態（オン。制御モード2ではオフ）に戻します |
| MS-IME入力設定 | スペース幅、句読点、キー割り当て（変換 / 無変換） |
| 自動起動 | Windowsへのログオン時に、自動で起動する方法 |
| 上級者向け設定 | 常駐の終了メニューの位置、ダークモード、ログ |
| バックアップ | 設定のバックアップと復元 |
| 拡張設定 | 全キーの一覧、編集、キー単位のリセット |
| バージョン情報 | バージョン、ライセンス、実行権限、保存場所 |

全キーの説明は、「AlwaysIME 設定キー一覧」を参照してください。

### 設定ファイルの場所

設定ファイルの名前は `AlwaysIME.dll.config` です。保存場所は、自動で決まります。

- 実行ファイルと同じフォルダーにあれば、**ポータブル**として動作します。
- なければ、`%AppData%\AlwaysIME` にあれば、**ユーザー別**として動作します。
- どちらにもない初回起動では、`AlwaysIME.portable` があればポータブル、なければユーザー別で作ります。

USBメモリなどで持ち運びたい場合は、初回起動の前に、`AlwaysIME.portable` を実行ファイルと同じフォルダーに置いてください（空のファイルで構いません）。

### 設定の自動修復

起動時に、設定ファイルを検証します。

- 足りないキーは、ひな形の値で補います。
- 不正な値は、そのキーだけひな形の値に戻し、通知します。元の値はログに残ります。
- 設定ファイルが壊れていた場合は、バックアップからの復元か、初期設定での作り直しを選べます。

## 自動起動

設定の「自動起動」で、次のいずれかを選びます。どちらも、現在のユーザーだけが対象で、管理者権限は不要です。

- **スタートアップ**: ログオン時に起動します。
- **タスクスケジューラ**: ログオンの10秒後に起動します。ログオン直後の混雑を避けたい場合に向いています。

実行ファイルを移動して、元の場所のファイルが無くなったときは、次回の起動時に登録内容を更新します。元の場所のファイルが残っているとき（別のフォルダーにコピーして起動したとき）は、登録を付け替えません。そのコピーに変えたい場合は、設定の「自動起動」を、いったん「自動起動しない」にして適用してから、選び直してください。組織の設定によっては、登録できない場合があります。

## 管理者権限で動くウィンドウを操作する

管理者権限で動くウィンドウは、通常のユーザー権限のAlwaysIMEからは操作できません（Windowsの仕様です）。AlwaysIMEも管理者権限で実行してください。

1. **手動で起動する**: 実行ファイルを右クリックして、「管理者として実行」を選びます。起動のたびに、UACの確認が出ます。
2. **ログオン時に自動で起動する**: AlwaysIMEを管理者として起動して、設定画面の「自動起動」で「タスクスケジューラに登録する（管理者権限で実行）」を選びます。次回のログオンから、UACの確認なしで、管理者権限で起動します。登録した後は、管理者として起動したAlwaysIMEからだけ、変更や解除ができます。

スタートアップフォルダーのショートカットを「管理者として実行」にしても、ログオン時には起動しません。

## バックアップと復元

- 設定を変更して、一定時間（既定は24時間）問題なく動作した状態を、**安定版**としてバックアップします。保持する世代数の既定は5です。
- 設定画面の「バックアップ」で、いますぐバックアップを作成できます。
- 復元では、日付と範囲（すべて / アプリ一覧のみ / それ以外のみ）を選びます。復元の前の設定も、別に保存されます。
- 保存先は、設定ファイルと同じ場所の `backup` フォルダーです。

## ログ

動作ログは、設定ファイルと同じ方式で保存されます。

- ポータブル: 実行ファイルと同じフォルダーの `logs`
- ユーザー別: `%AppData%\AlwaysIME\logs`

ウィンドウタイトルなど、作業内容が分かる情報は記録しません。出力の有無、レベル、サイズ、保存数は、設定画面の「上級者向け設定」で変えられます。問い合わせの際は、設定画面の「バージョン情報」の内容と、ログをお知らせください。

## トラブルシュート

| 症状 | 原因と対処 |
| --- | --- |
| 起動しない。「設定ファイルに問題が見つかりました」と出る | `AlwaysIME.dll.config.default` が無い、または壊れています。zipを展開し直してください。ウイルス対策ソフトに隔離されていないかも確認してください。 |
| 「設定の一部が不正だったため、ひな形の値に戻しました」と出る | 設定ファイルを手で編集したときに起こります。対処は不要です。元の値は、ログに残っています。 |
| 設定を保存できない、「書き込めない」と出る | Program Filesなど、書き込めない場所に置いています。書き込める場所へ移動してください。 |
| 一部のアプリで反応しない | そのアプリが管理者権限で動いている可能性があります。「管理者権限で動くウィンドウを操作する」を参照してください。WinUI / UWPのアプリには対応していません。 |
| 「MS-IME入力設定」に、「利用できません」と出る | 使用中のIMEが、対応していません。Windows 11の新しいMicrosoft IME（互換モードをオフ）を選んでください。 |
| 正規表現を保存すると、不正だと言われる | 書式を確認してください。カンマで区切るため、カンマを含めたい場合は、`\x2C` と書きます（例: `foo,bar` は `foo\x2Cbar`）。 |
| もう一度起動したら、再起動した | 多重起動はできません。2回目の起動は、起動中のAlwaysIMEに再起動を指示します。設定ファイルを手で編集したあとの、再読み込みに使えます。 |

## 更新

新しいバージョンのzipを、同じ場所へ上書きで展開してください。設定ファイルは、zipに含まれていないので、そのまま残ります。新しいバージョンで設定のキーが増えた場合は、起動時に、ひな形の値で補われます。

最新版は、[GitHub Releases](https://github.com/jarupxx/AlwaysIME/releases) で公開しています。

## アンインストール

1. トレイメニューの「常駐の終了」で、AlwaysIMEを終了します。
2. 設定の「自動起動」を「登録しない」にします（登録している場合）。
3. 展開したフォルダーを削除します。
4. ユーザー別として使っていた場合は、`%AppData%\AlwaysIME` も削除します。

異常終了や強制終了をした場合、MS-IMEのスペース、句読点、キー割り当てが元に戻らないことがあります。【要確認】その場合は、AlwaysIMEをもう一度起動して、正常に終了してください。

## 既知の制限

- 「MS-IME入力設定」は、Windows 11の新しいMicrosoft IME専用です。
- 管理者権限で動くウィンドウは、AlwaysIMEも管理者権限で実行する必要があります。
- WinUI / UWPなどのモダンUIフレームワークのアプリには、対応していません。
- 組織のポリシーによっては、タスクスケジューラへの登録や、IMEのレジストリへの書き込みが、制限される場合があります。
- 「制御しないアプリ」が前面のまま未入力タイムアウトを過ぎると、IMEが初期状態に戻ります。
