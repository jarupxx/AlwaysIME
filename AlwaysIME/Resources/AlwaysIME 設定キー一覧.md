# AlwaysIME 設定キー一覧

下書き ｜ 2026-10-27 ｜ 対象: AlwaysIME.dll.config の全28キー

※ 「ひな形の値」は、AlwaysIME.dll.config.default の値です。

## 共通のルール

- **保存場所**: ポータブルは実行ファイルと同じフォルダー、ユーザー別は `%AppData%\AlwaysIME` です。
- **形式**: XMLの `<appSettings>` の下に `<add key="キー" value="値" />` として書きます。
- **検証**: 起動時に、全キーを下の「形式・範囲」で検証します。不正な値は、そのキーだけひな形の値に置き換わります。キーが無ければ、ひな形の値で補います。
- **空欄**: 「空欄可」と書いたキーだけ、空欄にできます。それ以外の空欄は不正です。
- **一覧の区切り**: アプリ名や正規表現の一覧は、カンマ区切りです。アプリ名は、実行ファイル名（拡張子なし）で指定します。正規表現にカンマを含めたいときは、カンマを \\\\x2C と書きます（例: foo,bar は foo\\\\x2Cbar）。ImeOffTitle と UpdateTag は、各項目が正規表現として正しいかも検証します。書式が誤っている場合は、不正な値として扱います。
- **単位**: 時間は、キーごとに単位が違います（ミリ秒、分、時間）。表の「形式・範囲」を確認してください。
- **反映のタイミング**: 設定画面の「保存して閉じる」または「適用」で反映します。ただし、`IsDarkMode` のメニュー反映と `AppExitEnd` は、再起動後です。
- **手編集の注意**: ファイルを直接編集した場合の対処は、仕様書の「実行中の不正値」を参照してください。

## 動作の基本

| キー | 形式・範囲 | ひな形の値 | 説明 |
| --- | --- | --- | --- |
| AlwaysIMEMode | 1 / 2 / 3 / on / off | 1 | IMEの制御モードです。1: 常にオンにする。2: 通常はオフにする（ImeOffList と ImeOffTitle に載せたものだけ、オンにする）。3: 直前のIME状態を維持する。on は 1、off は 3 と同じです（旧バージョンとの互換）。 |
| intervalTime | 整数 30〜6000（ミリ秒） | 200 | IMEの状態を監視する間隔です。小さいほど反応が早くなりますが、負荷が増えます。 |
| NoKeyInputTime | 数値 0.1〜1440（分、小数可） | 3 | この時間、キーボードやマウスの入力が無かったら、IMEを初期状態（オン。AlwaysIMEMode が 2 ではオフ）に戻します。放置のあと使い始めるときに、状態をそろえるための動作です。ImeOffList と ImeOffTitle に載せたものは、一覧の指定どおりにします。AlwaysIMEMode が 3 でも、オンに戻り、引き継ぐ状態もオンになります。既知の制限: PassList のアプリが前面のままでも、同様に戻します。 |
| SuspendFewTime | 整数 1〜1440（分） | 5 | トレイメニュー「少し無効」で、機能を停止する時間です。 |
| SuspendTime | 整数 1〜1440（分） | 45 | トレイメニュー「しばらく無効」で、機能を停止する時間です。 |
| IsDarkMode | on / off | off | トレイメニューと設定画面を、ダークモードにします。メニューへの反映は、再起動後です。 |
| AppExitEnd | 0 / 1 | 1 | トレイメニューの「常駐の終了」の位置です。1: 末尾。0: 上部。反映は再起動後です。 |

## アプリの指定

| キー | 形式・範囲 | ひな形の値 | 説明 |
| --- | --- | --- | --- |
| PassList | 文字列（空欄可） | AlwaysIME,ShellExperienceHost | IMEを一切操作しないアプリです。 |
| ImeOffList | 文字列（空欄可） | cmd,powershell,pwsh,WindowsTerminal | アプリの切り替えやウィンドウタイトルの変化時に、IMEをオフにするアプリです。AlwaysIMEMode が 2 のときは意味が逆になり、載せたアプリだけ、IMEをオンにします（設定画面とトレイメニューの表記も「IME-ON」「IMEオンに登録」に変わります）。 |
| ImeOffTitle | 文字列（空欄可） | （空欄） | ウィンドウタイトルにマッチしたらIMEをオフにする正規表現です。全アプリ共通で適用されます。AlwaysIMEMode が 2 のときは、マッチしたらIMEをオンにします。例: `\.cs$` |
| UpdateTag | 文字列（空欄可） | `\(?更新\)?` | ウィンドウタイトルの変化を判定するとき、無視する部分の正規表現です。マッチした部分を除去してから判定します。 |

## 連携アプリ

連携アプリは、既定では使いません。7つのキーは、いずれも空欄がひな形の値です。AlwaysIMEが管理者権限で動作しているときは、設定していても連携アプリを起動しません（起動したアプリが管理者権限で動き、設定ファイルの書き換えで権限を昇格できてしまうためです）。

| キー | 形式・範囲 | ひな形の値 | 説明 |
| --- | --- | --- | --- |
| OnActivatedAppList | 文字列（空欄可） | （空欄） | アクティブになったときに、連携アプリを起動するアプリです。 |
| OnActivatedAppPath | 文字列（空欄可） | （空欄） | 上のアプリがアクティブになったときに起動する、連携アプリのパスです。存在しないパスを指定すると、警告が表示されます。 |
| OnActivatedArgv | 文字列（空欄可） | （空欄） | 連携アプリに渡すコマンドライン引数です。 |
| BackgroundAppList | 文字列（空欄可） | （空欄） | 非アクティブになったときに、連携アプリの起動を予約するアプリです。 |
| BackgroundAppPath | 文字列（空欄可） | （空欄） | 予約したアプリが非アクティブになり、DelayBackgroundTime が経過したときに起動する、連携アプリのパスです。 |
| BackgroundArgv | 文字列（空欄可） | （空欄） | 連携アプリに渡すコマンドライン引数です。 |
| DelayBackgroundTime | 数値 0.1〜1440（分、小数可）、空欄可 | （空欄） | 非アクティブになってから、連携アプリを起動するまでの時間です。空欄の場合は無効です。 |

## MS-IME入力設定

Windows 11の新しいMS-IME専用です。互換モードや、他のIMEでは動作しません。MsImeSwitch が 1 のときに有効です。非対応のIMEを選んでいるときは、設定画面の下部に警告を表示します（設定は無効になりません）。

| キー | 形式・範囲 | ひな形の値 | 説明 |
| --- | --- | --- | --- |
| MsImeSwitch | 0 / 1 | 0 | スペース・句読点の切替を有効にするかどうかです。1: 有効（トレイメニューから切替できます）。0: 無効（レジストリへの書き込みを行いません）。 |
| Punctuation | 「初期値,切替先」、各値は 0〜3、空欄可 | 1,3 | MS-IMEの句読点です。0: ，． 1: 、。 2: 、． 3: ，。 |
| SpaceWidth | 「初期値,切替先」、各値は 0〜2、空欄可 | 1,2 | MS-IMEのスペース入力です。0: 現在の入力モード 1: 常に全角 2: 常に半角 |
| KeyAssignment | 0 / 1 / 空欄 | （空欄） | 変換キー→IME-ON、無変換キー→IME-OFF の割り当てです。1: 割り当てる。0: 割り当てない。空欄: 管理しない（終了時には、変更前の設定に戻します）。 |

## バックアップ

保存先は、設定ファイルと同じ場所の `backup` フォルダーです。

| キー | 形式・範囲 | ひな形の値 | 説明 |
| --- | --- | --- | --- |
| BackupStableHours | 数値 0〜8760（時間） | 24 | 設定を変更してから、アプリがこの時間動作し続けたら、安定版バックアップを作成します。0 を指定すると、確認のたびに作成します。 |
| BackupKeep | 整数 1〜50 | 5 | 保持する安定版バックアップの世代数です。超えた分は、古いものから削除します。 |

## ログ

保存先は、ポータブルが実行ファイルと同じフォルダーの `logs`、ユーザー別が `%AppData%\AlwaysIME\logs` です。ウィンドウタイトルなど、作業内容が分かる情報は記録しません。

| キー | 形式・範囲 | ひな形の値 | 説明 |
| --- | --- | --- | --- |
| LogEnabled | 0 / 1（on / off / true / false も可） | 0 | 動作ログをファイルに出力するかどうかです。 |
| LogLevel | info / warn / error | info | 記録するレベルです。info: すべて記録。warn: 警告以上。error: エラーのみ。 |
| LogMaxSizeMB | 整数 1〜100（MB） | 1 | ログ1ファイルの最大サイズです。超えると、新しいファイルに切り替えます。 |
| LogKeep | 整数 1〜20 | 3 | 残しておく過去ログの数です。超えた分は、古いものから削除します。 |

## 検証ルールの注意

- 検証ルールの変更は、ひな形ではなくコード（`ConfigSchema.cs`）を修正します。キーを追加するときは、ひな形にも同じキーを追加してください。ひな形にキーが無いと、アプリは起動しません。
